9ThirtyOne USER Installation Guide

You get into 9ThirtyOne with the join link in your email. There is nothing to type, no password and no account to create. Keep that email: the link works any number of times.

Before you start

Turn off your content blocker for this site, or allow accounts.google.com. Signing in loads Google’s sign-in script, and blockers stop it. If you skip this, the sign-in screen just doesn’t move.

Leave it allowed afterwards

There is nothing here for a blocker to do. The only thing this app loads from outside is Google’s sign-in, so allowing this site costs you nothing — and switching the blocker back on can stop the app working with no clue as to why.

Get set up (every device)

  1. Tap the join link in your email. It opens in your browser and sets up your device.
  2. Sign in with Google, using the account your detachment has on its roster.
  3. If you won’t install the app, you’re done.

To use 9ThirtyOne as an app with its own icon, carry on to the next section.

Install it as an app (optional)

Start with 9ThirtyOne open in your browser after signing in. Once installed, it opens in its own window with the 931 icon and no address bar.

The installed app can start out blank

It has its own storage, separate from your browser. If it asks “Were you sent a join link?”, paste your join link from the email. On an iPhone it always asks.

Android (Chrome)

  1. Look for an “Add 9ThirtyOne to Home screen” banner near the address bar. If it appears, tap it and skip to step 4.
  2. If no banner appears, tap the three-dot menu (⋮) in the top-right corner.
  3. Select “Add to Home screen” or “Install app”. The wording varies by Chrome version.
  4. Confirm the name if prompted, then tap Add or Install.
  5. Open the 931 icon. If it asks for a join link, paste yours.

iPhone and iPad (Safari or Chrome)

  1. Tap the Share icon (a square with an upward arrow). In Safari it’s in the bottom toolbar; in Chrome it’s usually near the address bar or in the top-right menu.
  2. Scroll the share sheet and tap “Add to Home Screen”.
  3. Confirm or edit the name, then tap Add in the top-right corner.
  4. Open the 931 icon. It asks “Were you sent a join link?” Paste your join link.

Mac: Safari (“Add to Dock”, macOS Sonoma or later)

Safari’s app keeps a small back, forward and share toolbar. That’s an Apple limitation. Chrome or Edge gives a cleaner window.

  1. Click File, then Add to Dock (or the Share icon, then Add to Dock).
  2. Confirm the name and click Add.
  3. Open the 931 icon in the Dock. If it asks for a join link, paste yours.

Mac: Chrome or Edge

  1. Click the Install icon in the address bar (a monitor with a down arrow, or a ⊕ symbol). If you can’t see it, open the ⋮ menu, then Cast, Save, and Share, then Install 9ThirtyOne.
  2. Click Install in the prompt. The app is added to your Applications folder and Launchpad.
  3. If the app asks for a join link, paste yours.

Windows (Chrome or Edge)

  1. Click the Install icon in the address bar (a monitor with a down arrow, or a ⊕ symbol).
  2. If you can’t see it, open the ⋮ menu, then Apps, then Install 9ThirtyOne (Chrome). In Edge, open the … menu, then Apps, then Install this site as an app.
  3. Click Install in the prompt. The app is added to the Start menu and can be pinned to the taskbar.
  4. If the app asks for a join link, paste yours.

If something goes wrong

What you seeWhat to do
The sign-in screen doesn’t move Turn off your content blocker for this site, then try again.
The app icon opens a blank app Paste your join link when it asks “Were you sent a join link?”
Your phone was cleared or replaced Tap the join link in your email again.
You’re offline The app works offline only after you’ve set it up. First sign-in needs a connection.
