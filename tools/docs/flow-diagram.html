Why it takes a moment

Your device is never given access to the detachment’s Drive. The submission server does that work for you — and doing it safely is what costs the time.

The trade: a cadet’s phone is never handed the keys to the detachment’s folder, so no one can read anyone else’s answers by opening Drive. The cost is that every read and write makes the round trip above — which is why a busy screen takes a few seconds rather than being instant.
